我想象中的"杭电龙虾"，像一个多 Agent 集合：

## 1. 信息收集总结秘书 Agent

- 二课信息（订阅号）
- 志愿信息（QQ 群，爬取学校校园墙、QQ 频道的信息，比如二手出物、找老师联系方式等）
- **解决同学不能及时获取信息的痛点**

> 技术栈：RAG + Tool Use，爬虫数据加上数据清洗，再写入向量数据库

## 2. 执行秘书 Agent

- 帮助预约图书馆座位、教室、羽毛球场地、上课请假等
- 如果座位/场地已满，Agent 会实时监控，类似于高铁候补
- 当 Agent 准备完成任务时，在钉钉上弹出一个任务框来人工确认

## 3. 通知秘书 Agent

- 定时通知指定消息：明日天气、明日课程信息、最近学校的招聘会信息
- 结合你的课程日程来安排和提醒
- 比赛兴趣推送（RSS 流聚合推送，比如 CS、F1、NBA 等）

## 游戏化设计

- **经验值 (XP)** 来源：成功预约图书馆、按时打卡、完成一次志愿服务
- **等级进阶**：龙虾蛋 → 蒜蓉小龙虾 → 杭电精英虾 → **龙虾守望者 (King of HDU)**
- 做完任务有经验，可以升级，有种 game 的感觉，升级会解锁新的东西（称号？周年纪念章？志愿100小时称号？）

## 技术选型

**LangGraph** 框架，适合多 Agent 协作 + 复杂状态切换 + 长时间任务监控。
