写笔记时经常会用到一些 Markdown 写法，整理在这里，方便忘了的时候回来查。

## 多级标题

在行首使用井号和空格，井号数量对应标题级别。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 斜体、加粗与删除线

```markdown
*斜体*
**加粗**
~~删除线~~
```

*斜体*、**加粗**，以及 ~~删除线~~。

删除线属于常见扩展，例如 GitHub Flavored Markdown；不同编辑器和发布平台支持的语法可能不同。

## 链接与图片

标准图片写法是感叹号、方括号中的描述，以及圆括号中的图片路径。

```markdown
[网站名称](https://example.com)
![图片描述](./images/example.jpg)
```

相对路径要相对于发布环境来处理，不能把自己电脑上的绝对路径直接放进博客。

Obsidian 还支持这样的嵌入写法：

```text
![[图片名称.png]]
[[另一篇笔记]]
```

这些写法迁移到普通 Markdown 博客时需要转换。图片描述也应说明画面内容，方便图片未加载时理解。

## 字体颜色与下划线

Markdown 核心语法没有统一的字体颜色和下划线标记。支持 HTML 的环境可以这样写：

```html
<span style="color: RoyalBlue;">蓝色文字</span>
<span style="color: #DDA0DD;">粉色文字</span>
<u>带下划线的文字</u>
```

有些平台会过滤 HTML 或样式；MDX 的属性写法也取决于框架。颜色适合作为少量补充，重要内容还是用标题、加粗和清晰的文字表达。

## 脚注

支持脚注扩展的环境可以使用同一个标识，关联正文标记与文末解释。

```markdown
这是正文中的脚注示例[^note]。

[^note]: 这里写补充说明。
```

这是正文中的脚注示例[^note]。

[^note]: 脚注适合放补充说明，避免打断正文阅读。
