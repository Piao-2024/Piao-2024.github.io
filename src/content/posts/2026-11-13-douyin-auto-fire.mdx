然后我就上 Codex 去 GitHub 探索了下,找到了一个自动续火花的项目：[douyin-auto-fire](https://github.com/unmev/douyin-auto-fire)

技术上使用 Python 和 Playwright 操作抖音网页版：

用扩展程序导出 Cookie 加载登录状态，打开私信，搜索好友，再发送配置好的消息。

项目提供了 Docker 部署方式，正好可以放到自己的 NAS 上(~~其实是之前用的是的 GitHub Action，但后来老是掉登录,应该是抖音风控变严格了hhhhh~~

目前配置了 16 位好友。原本每天发个表情就够了，但跑起来之后，我又觉得，可以顺手加一点每天都会变化的内容。

我就想到每日一言和之前在 Telegram 群组里看到的 Year Progress.

## 加上一言和年度进度

每天获取一句话，缓存下来，追加给指定的一位好友。这样除了原来的表情，每天还会有一句不一样的文字,这样就会有趣一点哈哈哈哈哈哈

后来又加了年度进度，给所有好友的原有消息末尾追加一条，例如：

```text
2026 年度进度
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░ 86%
```

用当年已经过去的完整天数，除以这一年的总天数，再生成一条 20 格的进度条。闰年也按实际天数计算，百分比向下取整。每天零点更新，看着一点点往前走，有种看着时间流逝的感觉哈哈哈哈哈(~~话说 2027 年也快过去了🤔,时间都去哪了~~)

同一天的年度进度会缓存成一份，所有好友共用。当天重新运行时，也会继续使用这份内容。

最后接了一个钉钉的 Webhook，可以查看每天的情况.
